🌿 Sobre o AnimalDex

O que é o AnimalDex?

O AnimalDex é um projeto com o objetivo de apresentar várias informações sobre os diversos animais de maneira divertida e interativa, para que todos aprendam um pouco mais sobre os animais do mundo.

Nosso objetivo

O objetivo do site é fazer as pessoas se interessarem mais sobre os animais, ficarem informadas sobre características, habitat, dieta e muitas outras coisas interessantes, tudo isso de maneira interativa e divertida.

O que você encontra aqui?

  • Informações sobre diferentes animais.
  • Nomes científicos das espécies.
  • Classificação dos animais.
  • Uma pesquisa para encontrar animais facilmente.
  • Todos listados como se fosse uma Pokédex do Pokémon.
